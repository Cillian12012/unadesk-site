# unadesk.com

Заглушка сайта UnaDesk «Готовимся к запуску». Статическая страница: `index.html` + `favicon.svg`, RU/EN.

Публикуется через GitHub Pages из ветки `main` (папка `/`), домен — `unadesk.com` (файл `CNAME`).

Исходники бренда — в приватном репозитории `unadesk` (папка `site/`).

Страница не собирает данные посетителей: нет форм, аналитики, cookies и localStorage; шрифты (Unbounded, Manrope, JetBrains Mono, лицензия OFL) лежат в `fonts/`, запросов к сторонним сервисам нет.
